Notchy

A status light for Claude Code in your MacBook's notch. See what every session is doing, answer its questions without switching windows, and know the moment it's done.

Download for Mac Version 0.1, 0.8 MB. macOS 14 or later, Apple silicon and Intel.
A personal project, not affiliated with Anthropic.

30 second demo with sound. Made-up chats.

Install

  1. Open the download

    Open Notchy.dmg and drag Notchy onto Applications. If you open it straight from the disk image, it offers to move itself.

  2. Open Notchy

    Start it from your Applications folder.

    The first time, macOS says it can't check Notchy for malware, because it isn't signed with an Apple Developer ID. Open System Settings, then Privacy & Security, scroll down and click Open Anyway.

  3. Connect it to Claude Code

    Click Connect and show me. Notchy adds a few small hooks to ~/.claude/settings.json and keeps a backup of the file next to it. Then it plays a short demo.

  4. Start a new chat

    Hooks load when a chat starts, so new chats show up in the notch from now on. This works for Claude Code in the Claude app and in the terminal.

What the notch shows

Spinner: Claude is working. Each project keeps its own spinner color. The number is how many chats are working.

Amber "!": a chat needs your OK. You hear a soft sound, and the island opens by itself for a few seconds.

Green check: a chat is done. You hear a chime.

Everyday use

Hover the notch, or press Control Option N, to open the island.

See what Claude is doing
Each row shows the chat's title and what it's doing right now, like "Editing Hero.tsx" or "Reading 3 files".
Approve from the notch
When a chat asks permission, its row says what it wants, with Allow and Deny. Hover the line to read the full command first. If you're already in Claude when it asks, Notchy steps aside and you answer there as usual.
Know when it's done
A finished row shows Claude's last line, so you know if it's worth going back now.
Jump back
Click a row to open that exact chat in the Claude app. Terminal chats bring the terminal forward.
Keep it open
With the pointer on the island, swipe down with two fingers to pin it open. Swipe up to close it.
Your day
The bottom of the island shows how long Claude worked today and how many tasks it finished.

Settings

Open the island and click ⋯ in its top right corner. The same menu is in the menu bar icon, when your menu bar has room for it.

Sounds
One for "needs you" and one for "done". Hover a sound to hear it, click to choose it, or pick None.
Quiet during calls
No sounds while your microphone is in use. The island still opens.
Remind me after 5 minutes
One more nudge if a chat is still waiting for you.
Keep Mac awake while Claude works
Stops the Mac from going to sleep in the middle of a task.
Show on all displays
An island at the top of every screen, so it also works with the lid closed on a monitor.
Open at login
Starts Notchy when you log in.

If something looks wrong

A chat is stuck in the list
Hover its row and click the ×, or choose Clear finished sessions or Clear all sessions in the menu. Chats that stay silent for 10 minutes clear by themselves.
Rows say "Working" but not what Claude is doing
Choose Update Claude Code connection… in the menu, then start a new chat.
Notchy seems frozen
Choose Restart Notchy in the menu.
Notchy closed
The next prompt you send to Claude opens it again. If you quit it on purpose, it stays closed until you open it.

Privacy

Everything stays on your Mac. Notchy has no account, sends nothing over the network and uses no Claude tokens. It reads the events Claude Code passes to its hooks, and the Claude app's local session list to show chat titles and open the right chat.

Remove Notchy

Quit it from the menu and delete it from Applications. To put your Claude Code settings back exactly as they were, restore ~/.claude/settings.json.notchy-backup. Its hooks do nothing once the app is gone.
